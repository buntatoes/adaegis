ADAEGIS · 0.3.2

Install in four steps.

No account or build tools. Keep the extracted AdAegis folder somewhere you will not move it.

  1. Extract the ZIP

    Use Extract All or your archive app. Put the AdAegis folder in a lasting place, such as Documents. Do not load the ZIP itself.

  2. Open Extensions

    Browser menu → Extensions → Manage extensions. In Chrome or Chromium you can type chrome://extensions in the address bar.

  3. Turn on Developer mode

    Use the Developer mode switch on that page. That is how Chrome loads an extension that is not on the store.

  4. Load unpacked

    Select the AdAegis folder that contains manifest.json. Pin AdAegis from the puzzle-piece menu and open the popup.

What is on by default?

Network blocking. Page cleanup and YouTube filtering start off; turn either on in the popup if you want it. Chrome will ask for the site access that feature needs.

Page cleanup can start on sites you already have open. If a YouTube video is already playing, reload or wait for the next video. YouTube filtering is experimental — turn it off and reload if playback breaks.

Update without losing settings

Download the next ZIP from GitHub Releases. Extract it somewhere else first, then copy the new files into the same AdAegis folder you originally loaded. Click Reload on the Extensions page, then reload open sites.

Do not remove the extension or change folders for a routine update. There is no auto-updater.

Remove access or uninstall

Use Remove page access in the popup to drop site permissions. Network blocking stays available.

To uninstall, click Remove on the Extensions page, then delete the extracted folder.

If Load unpacked is missing

A work or school policy may block it. Use a personal Chrome profile, or ask the administrator. This package does not change browser policy.

This is a desktop extension. It does not install on the Chrome iPhone or Android apps.
