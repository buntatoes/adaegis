ADAEGIS · DESKTOP CHROMIUM · 0.3.0

Four steps to get started.

No account, terminal, or build tools needed. Keep the extracted AdAegis folder in a permanent location.

  1. Extract the ZIP

    Use Extract All or your computer's archive app. Move the AdAegis folder somewhere you will keep it, such as Documents. Do not load the ZIP itself.

  2. Open your browser's Extensions page

    Use the browser menu → Extensions → Manage extensions. In Chrome or Chromium you can instead type chrome://extensions into the address bar.

  3. Turn on Developer mode

    Enable the Developer mode switch on that page. This is the browser-supported method for loading an extension outside the store.

  4. Choose Load unpacked

    Select the extracted AdAegis folder containing manifest.json. Then pin AdAegis from the puzzle-piece menu and open its popup.

What starts automatically?

Basic network blocking. Page ad cleanup and experimental YouTube filtering start off; enable either in the popup if you want it. The browser asks for the site access each feature needs.

Reload the website after enabling a feature. YouTube filtering is experimental; turn it off and reload if playback breaks.

Update without losing your settings

Download the next ZIP from the project owner. Extract it elsewhere first, then copy the new AdAegis folder's contents into the same permanent folder you originally installed. Confirm file replacement, press Reload on AdAegis in the Extensions page, and reload open websites.

Do not remove/reinstall the extension or switch installation folders for a routine update. There is no automatic updater.

Remove access or uninstall

Use Remove page access in the popup to disable page features and release their site permissions. Basic blocking remains available.

To uninstall, click Remove on AdAegis in the Extensions page. You can then delete the extracted folder.

If Load unpacked is unavailable

A work/school browser policy or your browser variant may restrict it. Ask the administrator or use a supported personal desktop profile. This package does not change policies or bypass browser protections.

This desktop extension is not an installer for the Android or iPhone Chrome apps.

This is a testing build with automated regression checks, not a security certification. Full static checking and live-browser verification are still pending. See SECURITY.md for the hard-coded limits and known testing gaps.
